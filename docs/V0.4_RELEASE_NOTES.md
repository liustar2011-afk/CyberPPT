# CyberPPT-Script v0.4.0

## Theme

Source-faithful analytical Word-to-PPT compiler.

## Main changes

- source chapter structure becomes the default planning boundary;
- Foundation adds optional `source_structure`, fact grouping, visibility, relation basis/confidence/support;
- PLAN adds `source_structure_mode`, `source_scope`, `structural_operation`, `analysis_basis` and audience-scope handling;
- new `analysis-models.md` provides ten reasoning lenses for latent logic mining;
- explicit/inferred/speculative relation policy prevents unsupported analysis while allowing useful semantic deepening;
- new source index cache maps extracted Word hierarchy/paragraphs to semantic refs without creating a new content authority;
- new deterministic `audit-foundation` and `audit-plan` commands check inference support, chapter fidelity, cross-chapter movement and internal-only exposure;
- Critic shifts from audience-driven structural redesign to source-preserving analytical depth and page-expression quality;
- existing project artifacts remain schema-compatible because v0.4 fields are additive.

## User experience

The user still only needs ordinary language such as:

`根据这个 Word 生成 PPT 脚本。`

The default visible gates remain `脚本规划待确认` and `最终脚本已生成`.
