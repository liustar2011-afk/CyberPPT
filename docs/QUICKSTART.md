# Quick Start

## 用 Codex 打开仓库后

把 Word、PDF 或其他源材料放入当前任务，然后直接说：

> 根据这个 Word 生成 PPT 脚本。

Agent 会在内部完成材料理解、故事线设计、逐页问题—答案—证明链和重要内容覆盖检查。

正常情况下，第一次你看到的正式结果应当是：

> **脚本规划待确认**

你可以直接说：

> 继续。

最终应生成：

`projects/<slug>/dist/final-script.md`

（每个任务都会落在自己的 `projects/<slug>/` 目录下，想快速看某个项目当前进展，可以运行 `cyberppt-script status projects/<slug>`。）

## 想一次做完

> 根据这些材料直接生成完整 PPT 脚本，不用中途停下来确认。

## 想修改

> 第 8 页重写，保留前后页逻辑。

或：

> 整套再优化一遍，重点检查重复、遗漏、论证断裂和上屏文字过密。

## 你不需要做的事

不需要记住任何内部阶段名称，不需要调用 Skill，不需要操作 JSON，也不需要运行 CLI 才能完成脚本生成。
