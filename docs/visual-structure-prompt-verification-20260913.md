## 00｜执行顺序与内容边界

按以下顺序完成设计；这些步骤仅供内部推理，不绘入图片：

1. 理解页面使命，识别来源支持的主要内容组及关系，提炼可见内容。
2. 确定全页阅读起点、展开方式和信息落点，形成一个连贯的整体构图。
3. 分配各组位置、尺度与留白，建立全页一致的信息层级。
4. 为必要信息选择文字、图表、对象或场景，并统一局部样式。
5. 检查事实、主线、可读性及视觉秩序，修正后输出。

发生冲突时，依次保证：来源事实与显式保真要求 → 用户页面任务 → 全页构图与中文可读性 → 局部表达 → 材质与装饰。任何视觉选择都不得改变数字、主体、状态、责任、条件、范围或关系方向。

### 输入角色

- **页面标题**：提供主题与页面使命，默认由外部模板承载；正文图不重复绘制主标题或同义总标题，不预留固定标题带，不新增总结口号。局部标题直接说明对应内容组。
- **普通正文**：作为可提炼、合并、改写和重组的语义素材。完整讲稿不等于整段上屏文字。
- **保真文字**：仅消费显式 `fidelity_text` / 保真文字及用户指定的固定字符串。`required` 必须可见且准确；`if_rendered` 可省略，出现时必须准确。不得从普通正文自动推导逐字锁定要求。
- **上下文与制作说明**：仅供理解，不绘入画面。来源未提供的事实、宣传语、分类含义、因果、价值判断和业务承诺均不得补写。

### 来源内改写，禁止信息扩展

所有可见文字和业务关系都必须由本页内容素材或用户明确批准的补充内容直接支持。普通正文允许提炼、合并和换一种说法，改写后的每个命题都须能在输入中找到依据；不得借助行业常识、惯用汇报措辞或合理猜测补全内容。

- 来源只列资源、服务或应用领域时，保留对应清单及明示说明；不自动推导能力、优势、成效、战略意义或未来承诺。服务对象不得升级为已实现的业务效果，可能性不得升级为既成事实。
- 局部标题、图注、标签、底部总结和关系箭头与正文遵守同一来源边界。不得为形成视觉落点新增“价值／成效／意义”区、总结口号或拔高结论；来源没有总结时，画面可止于已给出的分类、组成或应用范围。
- 不为凑齐模块、填满空白或使各组对称而补写类别、例子、功能、对象、阶段及关系。缺少依据的内容直接省去，空间保留为留白。
- 绘制前逐项核对拟显示的短句、标题与关系：来源是否支持同一主体、动作、状态、范围和判断力度。无法对应的命题删除；仅部分得到支持时，退回来源明确的表述。核对过程不绘入图片。

数字、单位与对应对象保持邻近绑定；时间与状态、责任与主体、条件与结论保持同页可理解。必须出现的保真项用清晰文字承载。

## 01｜全页视觉主线：先建立整体

视觉主线是所有页面的全局要求，与信息密度和配图数量无关。读者应能自然辨认从哪里开始、如何理解主要内容、最终获得什么认识。信息落点可以是分类全貌、差异、组成、状态或来源已有结论。

主焦点提供注意力入口；视觉主线组织全页理解；布局骨架承载空间关系。放大一个对象只能形成焦点，仍须让其他主要内容与其共同构成整体。

先确定主要内容组之间的组织方式，再展开组内细节。通过位置、尺度、共同基线、对齐、包含、间距及必要的关系标签维持连续阅读。每个主要内容组都应有明确角色，局部焦点服从全页层级。避免先独立排好各区，再用连线拼接。

### 按语义选择组织方式

以下是选择依据，每页只采用与任务有关的组织逻辑；局部结构从属于全页，不将各类布局同时叠加。

| 来源支持的主关系 | 构图方式 | 必须保持的边界 |
|---|---|---|
| 并列分类、任务或事实集合 | 开敞分组、共同基线、顺序扫描 | 等权保持同级；不新增分类层级或优先级 |
| 共同维度下的比较 | 对齐行列、共享基准、往返阅读 | 同一指标采用一致尺度和口径 |
| 整体与部分、组成或范围 | 包含、分组、整体与局部对应 | 不把组成自动画成依赖或因果 |
| 步骤、对象流转或阶段衔接 | 连续路径及就近附着的动作与条件 | 仅在来源有方向时使用箭头 |
| 时间与状态变化 | 时间轴、日期与状态对应 | 真实比例需有数据，保留计划与已完成的区别 |
| 判断与证据、原因与结果 | 证据聚合或有依据的作用路径 | 仅表达来源已有判断和因果，保留条件 |
| 主体、职责与交互 | 主体分区、责任附着、带标签的交互 | 权限、方向与边界均有依据 |
| 数量、趋势或比例 | 数字或图表承担主体 | 使用真实数据；孤立规模数字不虚构趋势 |
| 共同对象与多个关联方 | 对象与关联方就近组织，按需放射 | 中心对象须有真实关系作用，不添加装饰性中心物 |
| 空间、部位或现场动作 | 对象主导、局部标注与对应说明 | 场景承担理解任务，标注锚定真实对象 |

阅读顺序不自动成为业务流程，整体关联不自动成为逐项配对。无来源依据的分组名称、双向箭头、闭环和层级不得为了构图加入。并列和比较页面也可以有清晰主线，无需强制单向推进。

## 02｜信息层级与空间秩序

全页先安排主要内容、必要支撑和补充说明的相对层级，再决定局部字号与配图。主内容获得足够阅读空间，支撑信息就近附着；同级内容使用一致的视觉语言。避免每个区域都配置大标题、大图标、彩色容器和独立主视觉。

使用统一的对齐系统、字号层级、线条风格和间距节奏贯穿全页。视觉强调集中在与页面使命直接相关的位置；来源等权时不以大小或颜色暗示业务优先级。主载体可由图表、对象、关系结构或有序内容集合承担，无需额外放置大型装饰物。

### 留白与密度

- 构图开始时安排连续外边距、主要组间空白通道及焦点周围的呼吸空间。
- 组间距明显大于组内间距；空白帮助分组，也通过对齐与方向维持跨组衔接，避免形成孤岛。
- 一般信息页可从约四分之一画幅的有效留白起步，按页面任务调整。该比例不作为删减必要语义的依据。
- 有效留白是连续、低干扰的空区。浅色照片、纹理、容器内部碎小缝隙不能代替主要留白。空区不自动补入内容或装饰。
- 内容过密时，先合并重复、提炼普通说明，再减少低价值配图与容器，重新分配空间。保持中文阅读尺度，不通过缩小字号、压缩字距或消除间隔塞入全文。

若必要内容仍无法容纳，应在制作反馈中说明范围过载并建议拆页，不擅自删除关键事实；反馈不绘入图片。调整内容、图片和间距后，重新检查整页主线，局部整齐不能代替整体连贯。

## 03｜文字提炼与表达

上屏文字围绕页面使命选择：主信息回答页面问题，必要支撑解释作用、差异、依据或条件；重复表述、铺垫及不影响理解的背景可省略，完整语义保留在输入稿中。

普通说明可提炼为“对象＋作用／特征／状态”的简明短句，其中作用、特征和状态仅采用来源明示内容；来源只给出名称时保留名称，定义、责任、条件及论证需要完整句时保留完整句。不得将整段讲稿搬入多个文字区，也不得将具体业务动作压缩成无实质含义的标签。

来源明示的分类集合、关键数字、主体、状态、责任及必要条件边界保持完整可获得。普通举例可选取代表项并保留举例属性，不能将部分示例表达为完整清单。缩写承担核心信息时，同页提供可理解的业务名称。

正文采用清晰、稳定的基础阅读尺度；局部标题适度放大；必要说明保持接近正文的可读尺寸；小字只用于补充性脚注。不固定全文字数、每组行数或模块数量，不强制各组使用同样长度的段落。

每项内容选择最有效的主载体：文字表达判断与限定，数字与图表表达有依据的数量关系，对象与场景表达空间和动作，分组与路径表达关系。相邻文字只补充主载体无法表达的信息，避免重复展示同一数字、判断或分类。

## 04｜局部视觉材料：按需使用

先形成全页结构，再添加能改善理解的视觉材料。图片、图标、卡片和连线均为可选手段，不能因其在风格文件中出现就全部使用。

### 场景与对象

信息密集时，优先减少场景化配图的数量与面积，将空间用于核心内容、关系表达和组间留白。仅保留对对象识别、空间关系或业务动作理解不可缺少的场景；以场景本身为主要表达对象的页面，按页面使命调整。

删除某张图后若理解没有明显损失，就移除该图并保留空白。不得为每个分类配置照片，不用横贯底部或占据边角的泛化场景填满画面。多个场景只有承担必要差异或不同动作时才同时使用。

场景与对应说明就近结合，保持真实、整洁、无品牌化的业务语境。生成场景只提供情境，不作为已验证的事实证据。场景内部不生成随机文字、日期、Logo、虚构界面或数据；来源要求的文字作为正式标注呈现。

默认不出现人物照片，严禁正面人物宣传照和多人开会的摆拍照片。仅在业务动作理解确需人物时采用从属于环境的自然侧面或背面形象。

### 图标、容器与连线

图标仅用于提高必要对象的识别效率，采用统一的简洁深蓝符号；不得为每条文字配置图标。普通抽象概念不自动转化为立体数据柱、中心底座或大型图标。

优先通过对齐、接近、包含和留白形成信息组。需要明确独立边界时才使用容器，采用轻描边、小圆角与低对比衬底；不将所有内容自动装入等宽等高卡片。

连线只承担明确关系。无方向关联用无箭头线，有方向的流转或作用用箭头；必要时以简短标签说明含义。端点锚定对应对象，避开文字，保持线宽、转折和箭头比例一致。连线不承担装饰或补救割裂布局的职责。

## 05｜视觉系统与精修

整体采用纯白、深蓝、平面哑光的编辑式商务信息图气质。清晰比例、准确对齐、舒适文字和空间节奏构成视觉完成度。

| 颜色 | 用途 |
|---|---|
| 纯白 `#FFFFFF` | 主体背景与留白 |
| 深蓝 `#12355B` | 主要文字、关键对象及关系 |
| 明亮蓝 `#1687E8` | 少量必要强调与主路径 |
| 正文色 `#303030`、次级色 `#6F7275` | 稳定的阅读层级 |
| 分隔线 `#C9CDD1`、局部浅蓝灰 | 轻量边界与局部衬底 |
| 琥珀色 `#D9772B` | 来源明确的风险、例外或约束 |

同级元素保持一致字重、颜色、线宽、圆角和内边距。普通文字容器、图标与路径保持平面；只有真实对象可保留轻微体积与自然照明。禁止大面积蓝灰雾化背景、厚重投影、玻璃拟态、全息面板、霓虹发光、悬浮光环、透明圆柱与水晶数据塔。

全页结构成立后再修整边缘、端点、基线、裁切和间距。主要区域割裂或阅读路径中断时，回到构图环节修正，局部材质精修不能代替结构修复。

视觉锚点：`coherent editorial composition, clear visual hierarchy, purposeful whitespace, highly legible Chinese typography, clean white canvas, restrained deep-blue palette, precise alignment, flat matte finish`。

## 06｜参考图与修改范围

参考图按指定角色使用：风格参考只继承色彩、线条、材质及完成度；版式参考只继承获准的空间组织；主体参考只继承对象身份与外观；内容参考只继承获准文字及数据。用户只要求参考风格时，不继承其布局、具体对象与文字。

局部修改时明确本轮修改项，保持其他已正确内容、构图、主线和风格稳定。用户要求整体构图或主线修复时，可在该范围内重组空间；始终保持来源事实和显式保真要求。修改后同时检查局部结果及全页连贯性，不因局部问题擅自扩展修改范围。

## 07｜输出验收

依次检查并修正以下问题；检查说明不绘入图片：

1. **内容准确**：关键数字、正式主体、状态和必要条件是否保留；保真项是否满足可见性及字面要求；逐项检查标题、标签、正文及总结能否对应来源；删除新增口号、效果承诺、价值判断、分类含义及无依据配对或关系。仅文字无错字不能判定内容准确。
2. **全页成立**：阅读起点、展开方式与信息落点是否清楚；主要内容组是否形成连贯整体；是否存在孤立大图标、竞争性焦点或局部整齐但全页割裂的区域。
3. **阅读舒适**：文字是否经过提炼且中文清楚；是否保留连续留白；是否有重复说明、拥挤、重叠或为填满画面加入的元素。
4. **表达克制**：每张图、每个图标、容器及连线是否承担必要作用；局部样式是否一致；是否误用参考图或出现禁用材质。

事实或整体构图未通过时，优先修正对应问题。最终画面应体现统一秩序、明确层级与连贯主线，所有局部表达共同服务于页面使命。
