# Sunburst OAuth 尺寸实测

日期：2026年9月9日。

三次请求均成功返回图片，三张原图均为 1774×887。当前通道在本次 high 质量、2:1、带风格参考图的样本中，没有按请求尺寸提高原生分辨率。

| 请求尺寸 | 原始尺寸 | 耗时 | 精确满足尺寸 |
|---|---|---|---|
| 2560x1280 | 1774×887 | 121.8 秒 | 否 |
| 3072x1536 | 1774×887 | 173.3 秒 | 否 |
| 3840x1920 | 1774×887 | 62.7 秒 | 否 |

## 方法与边界

使用 Stage 02 现有 `run_codex_image` OAuth 适配器进行隔离接口诊断，三次均通过 images 路径完成，无 Responses 回退。请求模型为 gpt-image-2.5-sunburst，quality=high，postprocess=False，附带同一张 palette-09 风格参考图。基准提示词来自上一轮正式生产的南网运营方案 P04，仅同步替换尺寸文字；业务内容与风格相同。每个尺寸调用一次。

逐张检查原始 PNG 可解码、尺寸，并确认输出副本与 raw 文件哈希相同，未执行缩放或增强。三张图已目视查看，均为完整的 2:1 中文信息图。未执行正式生产文字审计、语义验收或 PPTX 制作；这些图片是尺寸诊断样本。

本次无法证明后端的固定上限，也无法区分参数被忽略、内部档位选择或其他服务端策略。单次耗时受服务状态与生成内容影响，不能据此推断更大尺寸更快或更慢。实际后端模型版本未捕获。结论仅适用于当前账号、接口、模型请求与质量设置；公开 API 的高分辨率能力需要单独验证。

保持现有 Stage 02 2048×1024 交付画布即可；本次提高请求尺寸没有获得更多原生像素。本轮未修改生产代码或默认尺寸。
