# 页面级视觉意图编译设计

## 目标

在现有 ImageGen handoff 中增加一个轻量、确定性的页面级视觉意图编译步骤。它利用既有页面使命、核心判断、模块标题和上屏文字，生成简短的构图指导，使生图工具理解“本页要表达什么关系”，而不是机械地把每个模块转换成等权卡片、图标或流程节点。

本次改动保持单机脚本工具定位，不新增服务、模型调用、独立工作流或复杂配置系统。

## 范围

实现范围：

- 为内容页生成页面级视觉意图；
- 支持少量确定性的关系类型；
- 允许 Outline 页面提供可选覆盖；
- 将视觉意图送入最终 ImageGen 提示词；
- 重新生成当前 Style 09 项目的提示词并验证。

不在范围：

- 改写上屏文字；
- 替换 Style 09 全局风格契约；
- 为封面、目录、章节页或封底生成正文区提示词；
- 调用 ImageGen 或修改已生成图片；
- 引入新的大模型调用。

## 代码位置

在现有 `scripts/dual_image_overlay/imagegen_handoff.py` 中增加纯函数：

```python
build_page_visual_intent(
    page: ScriptPage,
    page_mission: str,
    override: dict[str, str] | None = None,
) -> str
```

保持功能集中在现有 handoff 文件中，不新增模块。

## 输入

自动编译只使用现有数据：

- `page_mission`：来自 Outline 页面的 `business_question`；
- `page.main_message`：核心判断；
- `page.module_titles`：模块标题及其顺序；
- `page.onscreen_text`：用于识别条件、阶段、因果、输入输出等关系信号。

Outline 页面可选增加：

```json
{
  "visual_intent": {
    "visual_thesis": "解释为什么首期选择双场景",
    "decision_relationship": "成熟度条件共同支撑首期选择",
    "recommended_composition": "首期选择为主，条件证据与后续准入为辅",
    "avoid_on_this_page": "五个等权条件卡和通用三步流程"
  }
}
```

覆盖字段均为可选；缺少的字段继续使用自动结果。无覆盖时不增加维护负担。

## 自动关系类型

编译器按以下顺序匹配，首个明确类型生效：

1. **决策与准入**：出现“筛选、选择、首期、后续、准入、条件”等信号；
2. **因果与判断**：出现“问题、原因、影响、需求、为什么”等信号；
3. **业务闭环**：出现“输入、处理、输出、反馈、复盘、闭环”等信号；
4. **阶段演进**：出现“当前、近期、中长期、阶段、分期”等信号；
5. **判断与证据**：无明确关系时的安全回退。

规则只决定视觉关系，不改变事实、模块顺序或上屏文字。

## 输出契约

页面级视觉意图固定输出四项：

```text
[Prompt context] Page-specific visual intent
- Visual thesis: {由页面使命与核心判断生成的视觉命题}
- Decision relationship: {识别出的页面关系}
- Recommended composition: {与页面关系匹配的构图指导}
- Avoid on this page: {本页特定禁用形式}
```

所有字段均明确为提示词上下文，不作为画面文字、页面标题或模块标签绘制。

最终提示词顺序固定为：

1. 页面使命；
2. 核心判断；
3. 上屏文字；
4. 页面级视觉意图；
5. Style 09 全局风格、行业场景、人物及负面约束。

页面级视觉意图只能补充 Style 09，不能删除、替换或弱化全局约束。

## 第19页预期结果

“场景选择与分期推进”应识别为“决策与准入”，核心表达为：

- 视觉命题：解释为什么月季分析和年度报告自动化优先进入首期，以及后续场景如何满足准入条件；
- 决策关系：五项成熟度条件共同支撑首期选择，后续场景位于明确的条件门禁之后；
- 推荐构图：首期选择为主视觉区域，筛选依据作为紧凑证据，后续扩展作为次级条件准入区；
- 本页禁用：五个等权条件卡、通用三步流程、时间线、场景缩略图墙。

该关系是决策结构，不是实施流程。

## 失败与回退

- 页面使命缺失：继续使用核心判断和模块标题编译，不阻断现有 handoff；
- 核心判断缺失：使用页面使命作为视觉命题基础；
- 模块标题不足：使用“判断与证据”安全回退；
- `visual_intent` 不是对象：忽略覆盖并使用自动结果；
- 单个覆盖字段为空：保留对应自动结果；
- 非内容页：沿用现有逻辑，不生成页面级视觉意图。

## 测试与验收

单元测试覆盖：

- 第19页命中“决策与准入”，并包含条件准入语义；
- 因果页、闭环页、阶段页命中各自关系；
- 无明显关系的页面使用安全回退；
- Outline 可选覆盖只替换指定字段；
- 页面使命或核心判断缺失时仍能生成有效结果；
- 非内容页不进入 ImageGen handoff；
- 页面级视觉意图位于上屏文字之后、Style 09 之前；
- 提示词明确禁止绘制视觉意图字段名和说明文字。

项目验收：

- 当前项目 24 个内容页全部重新生成；
- 32 页审阅稿仍保留完整页面标题；
- 页面使命、核心判断、上屏文字和视觉意图均进入对应内容页提示词；
- Style 09 既有行业场景、人物、信息密度和负面约束保持不变；
- 不调用 ImageGen，仍停在 Stage 02 送图脚本审批门禁。
