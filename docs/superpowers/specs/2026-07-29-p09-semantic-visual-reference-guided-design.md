# P09 参考图引导的语义主画面设计

## 目标

重新生成 P09“行业公共能力初步定位”。页面应适用于政企领导汇报与正式演讲：优雅、沉稳、成熟，同时由视觉承担业务解释，而不是把正文直接堆成两栏。

本次只调整 P09 单页生图输入，不修改双图法、生成链路、脚本编译器或其他页面。

## 参考图角色

用户提供的参考图只约束以下视觉语言：

- 明亮、克制的正式汇报底色；
- 深蓝建立的清晰中文信息层级；
- 成熟、可信、适合政企决策场合的气质；
- 真实行业语境与业务结构共同支撑判断。

不复制参考图的具体标题、四栏结构、箭头、底部平台、文字或业务对象。

## 主画面

采用一张连续的平面化编辑式业务语义插画，表现“行业公共预测工作台”：

1. 全国、区域、省级和重点行业供需信息进入公共预测能力；
2. 统一数据治理、组合模型、专家会商、成果生产与安全运行共同支撑预测预警；
3. 形成面向政府部门、电力企业与行业机构的行业分析服务；
4. 以清晰但克制的业务边界说明：公共能力服务行业分析，不替代实时调度控制、市场出清、企业生产计划和具体投资决策等专业系统。

主画面必须把输入、能力支撑、服务对象和职责边界组织成一条连续关系。行业场景和真实业务物件只能在它们能够解释具体业务含义时出现，不能作为无意义背景。

## 文字层级

文字只承担视觉无法替代的准确表达：

- 页面判断：面向行业的公共预测预警能力；
- 主画面内的必要业务标签：数据治理、组合模型、专家会商、成果生产、服务对象；
- 边界说明：服务行业分析，不替代专业运行系统。

其余内容通过语义插画、空间关系和少量短句共同表达。页面不再采用两栏正文堆叠。

## 视觉约束

- 画面以平面化、编辑式、写实质感的业务语义插画为主；
- 视觉约占页面主体，文字围绕主画面建立两到三级层次；
- 使用象牙白、深蓝、克制的浅灰与低饱和行业色；
- 保持正式演讲页的安静秩序与可信度；
- 不使用创意比赛式概念艺术、装饰性大场景或与判断无关的办公背景；
- 不把各项内容机械转换成图标、卡片或独立配图。

## 验收

新图必须同时满足：

1. 不读正文也能看出这是行业公共预测能力及其服务与边界；
2. 视觉元素能够分别解释数据、模型、会商、成果和服务对象；
3. 专业运行系统边界清楚，但不与公共能力形成两个平级文字栏；
4. 文字可读且没有重新退化成正文堆叠；
5. 整体气质适用于中国政企领导汇报。
