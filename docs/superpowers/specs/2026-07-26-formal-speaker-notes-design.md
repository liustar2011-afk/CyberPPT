# Formal Speaker Notes Design

## Goal

Speaker notes must read as a formal leadership briefing, not a host's transition script.

## Contract

- Start directly with the page judgment or factual conclusion.
- Use complete, speakable written Chinese.
- Organize each note as judgment, support, implication or boundary.
- Do not address the audience or describe the act of presenting.
- Reject phrases such as `各位同事`, `先把...说清楚`, `先说明`, `综合起来`, and `接下来看`.
- Preserve the source status and page boundary.

## Scope

Update the global writing reference and deterministic audit. Rewrite the 24 content-page notes in the current project and rebuild the canonical `script-final.md`. No new stage, provider, or workflow controller.
