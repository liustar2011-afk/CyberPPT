# Outline 作者契约

## 核心判断

正式 Outline 是编辑决策，不是 Source Truth 到页面字段的格式转换。候选编译器只负责完整列出来源节点、证据和可能页面；作者负责选择页面使命、主关系、证据职责、阅读层级和页间分工。

## 页面成立条件

一页只有同时满足以下条件才成立：

1. 独立回答一个具体受众问题；
2. 有一个来源支持且状态准确的核心命题；
3. 有一条可复述的主论证链；
4. 相对前后页有不可替代价值；
5. 核心证据分别承担 claim、reason、instance 或 boundary 职责；
6. 删除非必要细节后仍保留业务对象、关系、状态和边界；
7. 预计上屏能够形成单主题逻辑闭环。

## 直接推进测试

对每项拟上屏证据依次问：

- 它直接证明、解释、限定还是具体化页面命题？
- 删除它后，受众是否仍能从核心证据到达页面判断？
- 它回答的是本页问题，还是另一页、附件或执行阶段的问题？
- 它与同层内容是否属于同一分类维度和论证职责？

只有第一项明确且第二项为否时，才有充分理由进入受众层。

## 常见错误

- 因为来源重要而强制上屏；
- 因为证据相关而建立独立模块；
- 一个 content unit 混入对象、流程和资料要求；
- 把附件字段和操作清单提升为页面结构；
- 先固定页数或版式，再反向拼接证据；
- 用审计锚点替代自然的业务表达；
- 把审计通过误认为提纲已经专业成立。
