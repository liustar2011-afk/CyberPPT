# 黄金页面 03：Causal Chain

> 教学定位：展示 `directed chain` 的因果表达。Relation Units 是教学标签，映射到 AUTHOR Contract 的独立论证/推理单元，不新增运行时字段。

## 页面使命

说明分散的数据口径和版本为什么会逐级削弱跨周期风险预警。

## 核心结论

数据口径和版本分散会先造成同一指标计算基准不一致，继而使月季年结论难以校核、预测偏差难以追溯，最终削弱风险预警的持续更新能力。

## 主论证链

`数据口径和版本分散 → 同一指标计算基准不一致 → 跨周期结论难以校核 → 偏差难以追溯 → 风险预警难以持续更新`

## Argument Topology

`directed chain`

每个 Relation Unit 都是前一状态产生的直接业务后果，并为下一判断提供必要前提。每条边均需能够单独回答“为什么后一状态会发生”，不得用页面顺序或箭头代替因果依据。

## Relation Contract

- Node Role：起因、直接后果、中间后果、最终业务影响。
- Edge Semantics：前一节点真实产生后一节点，关系必须能够用“因为 A，所以 B”解释。
- Direction / Cardinality：单向 1 → 1 连续因果链。
- Invariant：每条边都必须独立通过“因为 A，所以 B”测试；排版、箭头或叙事顺序不能替代因果证据。
- Confusable With：Flow。
- Disambiguation Rule：Causal 的箭头回答“为什么 B 会发生”；Flow 的箭头回答“业务从 A 交接什么到 B”。

## Relation Units

1. 数据口径和版本分散，使同一指标在不同周期形成不同计算基准；
2. 计算基准不一致，使月度、季度和年度结论难以在同一尺度上比较与校核；
3. 结论难以稳定校核，使预测偏差难以定位到具体数据、规则或模型假设；
4. 偏差难以追溯，使复盘结果难以稳定回写，风险预警无法持续更新。

## 完整文字稿

月度、季度和年度预测若分别维护指标口径、数据版本和计算规则，同一指标可能在不同周期使用不同基准。基准一旦不一致，月度发现的风险就难以与季度、年度结论直接比较，同一风险也难以判断是业务变化还是口径变化造成。

跨周期结论缺少稳定校核基础后，预测偏差就难以进一步定位到具体数据版本、分析规则或模型假设。偏差原因无法追溯，复盘结论也难以准确回写到下一轮数据、规则和参数调整中，最终使风险预警难以形成持续更新的运行闭环。

## 上屏文字

- 数据口径和版本分散会逐级削弱跨周期风险预警的持续更新能力
  - 数据口径和版本分散，使同一指标形成不同计算基准
    - 月度、季度和年度分别维护指标定义、数据版本或计算规则时，同名指标可能具有不同基准
  - 计算基准不一致，使跨周期结论难以在同一尺度上比较与校核
    - 同一风险在月度、季度和年度中的差异无法直接判断来自业务变化还是口径变化
  - 跨周期结论难以稳定校核，使预测偏差难以定位
    - 偏差难以进一步追溯到具体数据版本、分析规则或模型假设
  - 偏差难以追溯，使复盘难以回写并削弱持续风险预警
    - 复盘结论无法稳定进入下一轮数据、规则和参数调整，风险判断难以连续改进

## 视觉结构

页面采用单一有向因果主链，所有箭头只表达“前因导致后果”。链路固定为：

`数据口径和版本分散 → 同一指标计算基准不一致：因果导致`

`同一指标计算基准不一致 → 跨周期结论难以校核：因果导致`

`跨周期结论难以校核 → 预测偏差难以追溯：因果导致`

`预测偏差难以追溯 → 风险预警难以持续更新：因果导致`

Evidence 紧贴所属节点，只解释直接父级为什么导致下一状态。核心结论位于链路上方或终点附近的总论区域，不重复作为额外流程节点。

## 演讲者备注

这条因果链从一个可验证的起点出发：同一指标在不同周期使用不同口径或版本，会直接形成不同计算基准。基准不同后，月季年结论便缺少共同比较尺度，同一风险的差异也难以判断究竟来自业务变化还是统计口径变化。

结论无法稳定校核，偏差原因就难以继续追溯到数据、规则或模型假设。复盘缺少可追溯依据后，调整动作无法稳定回写到下一轮预测，风险预警也就难以形成持续改进闭环。

## 作者自检

1. 每个 Relation Unit 都明确陈述“前一状态造成的直接后果”。
2. 四条因果边均可独立通过“因为 A，所以 B”测试。
3. 任意删除一个中间节点，前后两端的因果解释都会出现明显缺口。
4. 页面不混入实施步骤、业务交接或时间阶段，避免与 Flow / Roadmap 混淆。
5. Evidence 只证明直接父级与下一后果之间的因果关系。
6. 上屏纯文本和视觉结构均可恢复同一条因果链，Stage2 无需根据排版猜测关系。
