# 黄金页面 07：Roadmap

> 教学定位：展示 `roadmap`。每个阶段必须同时给出进入条件与新增状态，阶段名称本身不能替代业务结果。

## 页面使命

说明统一预测体系如何从当前分散基础经过三次可验证状态跃迁，最终进入常态运行闭环。

## 核心结论

统一预测体系从“数据与周期业务已存在但规则分散”的当前状态起步，依次形成共同输入、跨周期可比结论和常态复盘回写机制，最终进入持续运行状态。

## 主论证链

`S0 当前分散基础 → S1 共同输入可复用 → S2 跨周期结论可比较 → S3 复盘回写常态化`

## Argument Topology

`roadmap`

Roadmap 以状态为节点、以前置条件为跃迁依据。每个 Relation Unit 同时回答“进入这一阶段需要满足什么条件”和“阶段完成后形成什么新状态”；上一阶段的新状态必须能够成为下一阶段的实际进入条件。

## Relation Contract

- Node Role：起点状态、阶段状态、进入条件、终点状态。
- Edge Semantics：上一阶段形成的新状态满足下一阶段前置条件后发生状态跃迁。
- Direction / Cardinality：S0 → S1 → S2 → S3 的单向状态演进。
- Invariant：每阶段都必须同时包含进入条件和新状态；新状态必须成为下一阶段的实际前置条件。
- Confusable With：Flow。
- Disambiguation Rule：Roadmap 的箭头表示“满足条件后的状态跃迁”；Flow 的箭头表示“真实业务交接”。

## Current State｜S0

月度、季度和年度预测业务已经存在，但核心数据目录、指标口径、版本规则和判断尺度仍相对分散，跨周期结论缺少稳定共同基准。

## Relation Units

1. 阶段1｜数据规则贯通
   - 进入条件：首批核心数据、指标、周期范围和责任边界已经明确；
   - 新状态 S1：核心数据目录、指标口径和版本规则统一，月季年能够复用同一套可追溯输入。
2. 阶段2｜跨周期试运行
   - 进入条件：S1 共同输入已稳定，可连续支持月度、季度和年度分析；
   - 新状态 S2：月度滚动、季度校核和年度展望在同一框架联合运行，关键结论可比较，主要偏差可定位。
3. 阶段3｜闭环固化
   - 进入条件：S2 关键结论能够稳定复核，主要偏差能够追溯到数据、规则或模型假设；
   - 新状态 S3：会商审校、成果发布、误差复盘和规则参数回写形成常态机制。

## Target State｜S3

统一预测进入持续运行状态：共同输入可复用、跨周期结论可校核、预测偏差可追溯、复盘结果可持续回写。

## 完整文字稿

统一预测体系从已有月度、季度和年度预测业务基础起步。当前已经具备周期性业务和数据来源，但核心数据目录、指标口径、版本规则和判断尺度仍相对分散，因此第一阶段需要先明确首批核心数据、指标、周期范围和责任边界，完成数据规则贯通。阶段完成后形成 S1：月季年能够复用同一套可追溯输入。

当共同输入能够稳定、连续支撑不同周期分析后，进入第二阶段跨周期试运行。月度滚动、季度校核和年度展望在同一框架联合运行，检验关键结论是否可比较、主要偏差是否可定位；完成后形成 S2。

当 S2 的关键结论能够稳定复核，主要偏差能够追溯到具体数据、规则或模型假设后，进入第三阶段闭环固化。会商审校、成果发布、误差复盘及规则参数回写形成常态机制，最终形成 S3 持续运行状态。

## 上屏文字

- 统一预测体系通过三次可验证状态跃迁进入常态运行
  - 当前状态 S0｜周期业务已存在，数据口径、版本规则和判断尺度仍相对分散
  - 阶段1｜数据规则贯通
    - 进入条件：首批核心数据、指标、周期范围和责任边界明确
    - 新状态 S1：共同输入可复用、可追溯
  - 阶段2｜跨周期试运行
    - 进入条件：S1 共同输入稳定，可连续支持月季年分析
    - 新状态 S2：跨周期结论可比较、可相互校核，主要偏差可定位
  - 阶段3｜闭环固化
    - 进入条件：S2 关键结论稳定复核，主要偏差可追溯
    - 新状态 S3：审校、发布、复盘和回写形成常态机制
  - 目标状态｜共同输入可复用｜跨周期结论可校核｜偏差可追溯｜复盘可持续回写

## 视觉结构

页面固定显示 S0、S1、S2、S3 四个状态节点，阶段名称作为对应跃迁的业务标签，进入条件贴近状态边呈现。关系固定为：

`S0 当前分散基础 → S1 共同输入可复用：顺序演进｜进入条件：首批数据、指标、周期范围和责任边界明确`

`S1 共同输入可复用 → S2 跨周期结论可比较：顺序演进｜进入条件：共同输入稳定并可连续支持月季年分析`

`S2 跨周期结论可比较 → S3 复盘回写常态化：顺序演进｜进入条件：关键结论稳定复核且主要偏差可追溯`

箭头只表达满足条件后的状态跃迁。起点和终点必须显式可见；没有来源支持具体年份时，不自行添加年份或固定时间承诺。

## 演讲者备注

Roadmap 的核心是状态变化。当前 S0 已经有月季年业务基础，但共同规则仍不稳定；第一阶段形成 S1 共同输入，第二阶段利用 S1 形成 S2 可比较、可校核的跨周期结论，第三阶段再以 S2 为基础形成 S3 常态复盘回写机制。

每一次推进都有明确进入条件和可验收的新状态，因此路线图可以判断“当前在哪里、满足什么条件才能进入下一阶段、完成后新增什么能力”，也能与日常业务流程清楚区分。

## 作者自检

1. 页面明确显示 Current State S0 和 Target State S3。
2. 三个 Relation Units 均同时包含进入条件和新状态。
3. S1、S2 均实际成为后一阶段的前置条件，状态链不存在空跳。
4. 每条箭头表达状态跃迁，阶段之间没有使用业务交接物替代进入条件。
5. 未有来源支持时不自行虚构年份；状态条件承担推进依据。
6. 上屏纯文本和视觉结构均能恢复 S0 → S1 → S2 → S3 及每次跃迁的触发条件。
