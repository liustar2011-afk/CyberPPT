# 黄金页面 07：Roadmap

> 教学定位：展示 `roadmap`。每个阶段必须同时给出进入条件与新增状态，阶段名称本身不能替代业务结果。

## 页面使命

说明统一预测体系如何从数据贯通逐步进入跨周期试运行并最终形成常态闭环。

## 核心结论

统一预测体系按“数据规则贯通—跨周期试运行—闭环固化”三阶段推进，每阶段以可验证的新状态作为进入下一阶段的条件。

## 主论证链

`当前分散基础 → 数据规则贯通 → 跨周期试运行 → 闭环固化 → 常态运行状态`

## Argument Topology

`roadmap`

阶段之间具有前置条件。每个 Relation Unit 都同时回答“何时进入”和“进入后新增什么可验证状态”。

## Relation Units

1. 数据规则贯通：完成核心数据目录、指标口径和版本规则统一后，形成可复用共同输入；
2. 跨周期试运行：共同输入稳定后，月度、季度和年度在同一框架中联合校核，形成可比较结论；
3. 闭环固化：跨周期结果能够稳定复核后，把审校、发布和误差复盘固化为常态机制。

## 完整文字稿

统一预测体系从现有分散数据和周期业务基础起步。第一阶段先贯通核心数据目录、指标口径和版本规则；完成后，月度、季度和年度能够复用同一套可追溯输入，这是进入联合试运行的前提。

第二阶段以共同输入稳定为条件，将月度滚动、季度校核和年度展望放入同一分析框架联合运行，并通过相互校核形成可比较的跨周期结论。只有当关键结论能够连续复核、主要偏差可以定位，才能进入闭环固化。

第三阶段把会商审校、成果发布、误差复盘及规则参数回写固化为常态机制，使统一预测从项目建设状态转为持续运行状态。

## 上屏文字

- 统一预测体系按三阶段推进，每阶段以可验证新状态作为下一阶段进入条件
  - 阶段1｜数据规则贯通：形成可复用、可追溯的共同输入
    - 进入条件：明确首批核心数据、指标和周期范围
    - 新状态：核心数据目录、指标口径和版本规则统一，月季年可复用同一输入
  - 阶段2｜跨周期试运行：形成可比较、可相互校核的月季年结论
    - 进入条件：共同输入稳定，可连续支持月度、季度和年度分析
    - 新状态：月度滚动、季度校核和年度展望在同一框架联合运行，主要偏差可定位
  - 阶段3｜闭环固化：形成审校、发布、复盘和回写的常态机制
    - 进入条件：跨周期关键结论能够稳定复核，偏差原因可以追溯
    - 新状态：复盘结果持续回写数据版本、分析规则和预测参数，统一预测进入常态运行

## 视觉结构

主体采用明确的阶段演进路径。每个阶段至少可见三部分：阶段名称、进入条件、新达到状态。阶段箭头只表达满足条件后的演进，不用装饰性箭头制造确定时间。起点显示现有基础，终点显示常态运行状态；如没有来源支持具体年份，不自行添加年份。

## 演讲者备注

路线推进的重点是每一步形成什么新能力。第一阶段先让数据、指标和版本规则可复用，使不同周期拥有共同输入；这是后续联合分析能够成立的基础。

第二阶段把月度、季度和年度放到同一框架中试运行，检验结论是否可比较、偏差是否可定位。只有这些条件稳定满足后，第三阶段才把会商、发布、复盘和回写固化为常态机制。这样每一步都可以验收，也能明确进入下一阶段的实际条件。

## 作者自检

1. 页面有明确起点、三个阶段和目标状态。
2. 每个 Relation Unit 都包含进入条件与新增状态，不能只有“近期、中期、远期”或阶段名。
3. 下一阶段依赖上一阶段形成的新状态，关系具有真实前置条件。
4. 未有来源支持时不自行虚构年份；触发条件可以承担时间推进依据。
5. Evidence 解释阶段为何可进入以及完成后新增什么能力。
6. 上屏纯文本能够恢复阶段顺序、触发条件和状态变化。
