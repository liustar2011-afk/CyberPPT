# 黄金页面 06：Comparison

> 教学定位：展示 `comparison`。比较对象必须使用同一评价维度，差异结论由同维度证据建立，避免把无关特征拼成“优劣对比”。

## 页面使命

说明分散预测方式与统一预测体系在关键运行能力上的差异。

## 核心结论

统一预测体系通过统一数据版本、分析维度、跨周期校核和复盘机制，使预测工作形成可比较、可追溯、可持续更新的运行能力。

## 主论证链

`固定比较对象（分散预测方式 / 统一预测体系） × 四个共同评价维度 → 运行能力差异结论`

## Argument Topology

`comparison`

所有比较行都使用同一对对象：分散预测方式与统一预测体系。每一行只改变评价维度，不改变比较对象或判断标准。状态差异通过固定列位、共同维度和成对证据表达，不使用方向箭头表达对象关系。

## Relation Contract

- Node Role：固定比较对象 A / B + 多个共同评价维度。
- Edge Semantics：A 与 B 在同一评价维度上形成状态差异，不表示 A 流转、演进或转化为 B。
- Direction / Cardinality：无流程方向；两个固定对象 × N 个评价维度。
- Invariant：每一行都必须使用同一对比较对象和同一评价标准，左右 Evidence 必须成对。
- Confusable With：Mapping / Roadmap。
- Disambiguation Rule：Comparison 回答“A 与 B 在维度 D 上有什么差异”；Mapping 回答“A 对应什么 B”；Roadmap 回答“状态如何逐步跃迁”。

## Relation Units

1. 数据基础｜分散方式：各报表、周期或团队分别维护版本；统一体系：统一目录、指标口径和数据版本；
2. 分析范围｜分散方式：以单点总量判断为主；统一体系：纳入结构、区域、时段、区间、概率和情景；
3. 周期衔接｜分散方式：月度、季度和年度相对独立生产；统一体系：月季年在共同框架内相互校核；
4. 运行反馈｜分散方式：成果发布后缺少持续复盘；统一体系：误差复盘持续回写数据、规则和参数。

## 完整文字稿

分散预测方式与统一预测体系的差异可以从四个共同维度判断。数据基础方面，分散方式容易形成不同报表、周期和团队分别维护版本的情况；统一体系要求目录、指标口径和数据版本一致并可追溯。分析范围方面，分散方式以单点总量判断为主；统一体系将结构、区域、时段、区间、概率和情景纳入共同分析框架。

周期衔接方面，月度、季度和年度相对独立生产时，同一风险难以相互验证；统一体系通过共同框架实现滚动、校核和展望之间的连续衔接。运行反馈方面，预测结果发布后若缺少复盘，偏差难以进入下一轮规则和参数调整；统一体系通过误差复盘形成持续回写。四项差异共同决定预测工作能否沉淀为可比较、可追溯、可持续更新的运行能力。

## 上屏文字

- 统一预测体系在四个共同维度上形成可比较、可追溯、可持续更新的运行能力
  - 评价维度｜数据基础
    - 对象A｜分散预测方式：各报表、周期或团队分别维护版本
    - 对象B｜统一预测体系：目录、指标口径和数据版本统一且可追溯
  - 评价维度｜分析范围
    - 对象A｜分散预测方式：以单点总量判断为主
    - 对象B｜统一预测体系：结构、区域、时段、区间、概率和情景共同解释风险
  - 评价维度｜周期衔接
    - 对象A｜分散预测方式：月度、季度和年度相对独立生产
    - 对象B｜统一预测体系：月度滚动、季度校核和年度展望在共同框架内相互验证
  - 评价维度｜运行反馈
    - 对象A｜分散预测方式：成果发布后缺少持续复盘
    - 对象B｜统一预测体系：偏差持续回写数据版本、分析规则和预测参数

## 视觉结构

- 视觉对象：固定比较对象 A“分散预测方式”和 B“统一预测体系”，以及四个共同评价维度“数据基础、分析范围、周期衔接、运行反馈”。
- 关系语义：A 与 B 在每个共同评价维度上形成 `comparison` 状态差异；同一对象跨行保持身份不变，四行共同建立运行能力差异结论。
- 方向 / Cardinality：对象之间无流程方向；固定 2 个对象 × 4 个评价维度。Comparison 不表示 A 流转到 B，也不表示问题响应或阶段跃迁。
- 分组 / 层级：左右双列固定为 A / B，四个评价维度作为稳定行头；每行两端 Evidence 成对，横向读取某一维度的状态差异，纵向读取同一对象的整体能力特征。
- 禁止误读：不得添加 A→B 箭头暗示迁移、升级或必然演进；不得中途更换比较对象、评价口径或证据尺度；不得把四行顺序解释为实施阶段。

可解析无方向关系：

`比较对象｜分散预测方式 vs 统一预测体系：对照比较`

四个评价维度属于比较上下文，不成为额外关系端点；Stage2 可改变双列的具体视觉载体，但必须保留固定对象对、共同维度和无流程方向。

## 演讲者备注

Comparison 是否成立，关键看“比较对象固定、评价维度一致、两端证据成对”。任一行若更换了对象、评价口径或证据尺度，该行就失去可比性；页面即使保持左右双列，也不能继续视为有效 Comparison。

这页不使用方向箭头，因为两列之间表达的是同一维度下的状态差异，不包含时间演进、业务交接或问题响应。讲解时重点指出差异由共同评价标准建立，避免把“分散方式”和“统一体系”讲成必然的迁移路径。

## 作者自检

1. 上屏统一采用“评价维度｜D / 对象A｜状态 / 对象B｜状态”的微语法。
2. 五项视觉结构合同完整，可恢复固定对象、比较关系、无流程方向、双列层级和禁止误读项。
3. `比较对象｜A vs B：对照比较` 可被 Stage2 恢复为 non-directional `comparison`，不需要制造假箭头。
4. 所有比较行都使用同一对比较对象，没有中途切换主体。
5. 四个 Relation Units 都是可命名的统一评价维度。
6. 每行左右两端具有可比性，证据解释同一维度的状态差异。
7. 比较对象之间没有使用方向箭头，页面不会被误读为流程、迁移路径或实施路线。
8. 核心结论由四项差异共同建立，没有额外引入未比较的新判断。
9. 视觉上能横向读取每一行，也能纵向理解两个对象的整体能力特征。
