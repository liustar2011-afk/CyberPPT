# 黄金页面 04：Convergence

> 教学定位：展示 `convergence`。多个输入分别贡献信息并共同形成一个结果，不虚构输入之间的时间先后。

## 页面使命

说明供给边界、需求压力、互济缓释和波动扰动如何作为独立输入共同形成供需风险判断。

## 核心结论

供给边界、需求压力、互济缓释和波动扰动四类独立输入共同收敛为综合供需风险判断，任何单一输入都不足以独立代表整体风险。

## 主论证链

`供给边界输入 + 需求压力输入 + 互济缓释输入 + 波动扰动输入 → 综合供需风险判断`

## Argument Topology

`convergence`

四个 Relation Units 都以“独立输入角色”进入同一个结果节点。输入之间不建立默认先后关系，也不要求属于同一来源类型；它们的共同点是都直接贡献综合供需风险判断所需的信息。

## Relation Contract

- Node Role：多个独立输入 + 一个共同结果节点。
- Edge Semantics：各输入分别贡献必要信息，共同生成或支撑同一结果。
- Direction / Cardinality：N → 1；输入之间无默认方向。
- Invariant：所有输入必须直接汇入共同结果，不能退化为平行卡片，也不能在输入之间虚构流程或因果。
- Confusable With：Parallel。
- Disambiguation Rule：Convergence 回答“哪些独立输入共同生成一个结果”；Parallel 回答“一个结论由哪些同层组成维度支撑”。

## Relation Units

1. 供给边界输入｜实际可用能力刻画系统可调用供给上限；
2. 需求压力输入｜负荷峰值、持续时长和爬坡速度刻画需求侧平衡压力；
3. 互济缓释输入｜跨区跨省交易与可调用资源刻画本地缺口可缓释程度；
4. 波动扰动输入｜天气变化和新能源出力偏差刻画短期供需不确定性。

## 完整文字稿

综合供需风险判断需要四类相互独立的输入。供给边界输入关注系统能够实际调用多少供给能力，检修、故障和受限情况会使名义装机与实际可用能力产生差异。需求压力输入关注负荷峰值、持续时长和快速爬坡，决定平衡压力出现的时点和强度。

互济缓释输入关注跨区跨省交易及外部可调用资源，判断本地缺口能够被外部资源缓释到什么程度。波动扰动输入关注天气变化和新能源出力偏差，刻画短期供需两侧的不确定性。四类输入分别贡献信息，并在同一分析框架内汇入对缺口规模、发生时段和风险概率的综合判断。

## 上屏文字

- 四类独立输入共同收敛为综合供需风险判断
  - 供给边界输入｜实际可用能力刻画可调用供给上限
    - 依据｜检修、故障和受限情况会使名义装机与实际可用能力产生差异
  - 需求压力输入｜负荷峰值、持续时长和爬坡速度刻画平衡压力
    - 依据｜峰值水平、持续时间和快速爬坡共同决定压力出现的时点与强度
  - 互济缓释输入｜跨区跨省交易与可调用资源刻画缺口缓释空间
    - 依据｜外部互济能力直接改变本地供需缺口的实际风险水平
  - 波动扰动输入｜天气和新能源偏差刻画短期不确定性
    - 依据｜温度变化、风光出力偏差会同时改变需求和可用供给的短期波动

## 视觉结构

页面围绕唯一共同结果“综合供需风险判断”组织四个独立输入入口。四条关系固定为：

`供给边界输入 → 综合供需风险判断：共同支撑`

`需求压力输入 → 综合供需风险判断：共同支撑`

`互济缓释输入 → 综合供需风险判断：共同支撑`

`波动扰动输入 → 综合供需风险判断：共同支撑`

四个输入保持同等入口地位，各自携带所属 Evidence，彼此之间不连线。结果区可进一步解释缺口规模、发生时段和风险概率，但这些内容属于共同结果的输出含义。

## 演讲者备注

讲解时先指出唯一共同结果，再解释“为什么需要多个独立输入”。四个输入之间无需建立先后顺序；删除其中一个输入会降低综合判断的完整性，但不会让其他输入之间自动形成流程或因果关系。

判断 Convergence 与 Parallel 的关键在结果节点：如果页面必须把多路信息汇到同一个可命名结果，采用 Convergence；如果只是从同一维度拆出若干兄弟组成项，并不存在独立汇入动作，则采用 Parallel。口头讲解应围绕这一边界展开，不再逐项复述四类输入内容。

## 作者自检

1. 四个 Relation Units 均采用“输入角色｜该输入对共同结果贡献什么信息”的句法。
2. Evidence 统一采用“依据｜具体事实/机制”，不机械重复输入标题。
3. 四个输入都直接指向同一结果节点，不通过其他输入中转。
4. 输入之间没有被虚构成先后步骤、因果链或实施顺序。
5. 每项 Evidence 只解释其输入为何影响综合风险判断。
6. 视觉上四条输入关系必须共同汇入同一结果区，不能退化成四张平行卡片加一个孤立结论。
7. 上屏纯文本和视觉结构均可恢复 `N 个独立输入 → 1 个共同结果`。
