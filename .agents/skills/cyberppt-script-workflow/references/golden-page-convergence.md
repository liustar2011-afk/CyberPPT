# 黄金页面 04：Convergence

> 教学定位：展示 `convergence`。多个输入分别贡献信息并共同形成一个结果，不虚构输入之间的时间先后。

## 页面使命

说明供给、需求、市场和外部条件如何共同形成供需风险判断。

## 核心结论

供给可用能力、负荷变化、市场互济和天气及新能源偏差共同收敛为供需风险判断，任何单一输入都不足以独立代表整体风险。

## 主论证链

`供给能力 + 负荷变化 + 市场互济 + 天气/新能源偏差 → 综合供需风险判断`

## Argument Topology

`convergence`

四个 Relation Units 是相互独立的输入贡献，最终汇入同一风险判断。输入之间没有默认先后顺序。

## Relation Units

1. 供给可用能力决定系统可实际调用的供给边界；
2. 负荷变化决定需求峰谷与爬坡压力；
3. 市场互济改变本地缺口可被外部资源缓释的程度；
4. 天气和新能源偏差增加短期供需的不确定性。

## 完整文字稿

供需风险由多类输入共同决定。装机规模只能说明名义供给基础，检修、故障和受限情况进一步决定实际可用能力；需求侧的峰谷变化和快速爬坡会改变平衡压力；跨区跨省交易和互济能力会改变本地缺口的可缓释程度；天气变化及新能源出力偏差又会扩大短期不确定性。

因此，综合研判需要让供给、需求、市场和外部扰动在同一分析框架内汇聚，形成对缺口规模、发生时段和风险概率的共同判断。

## 上屏文字

- 供给、需求、市场和外部扰动共同收敛为供需风险判断
  - 供给可用能力决定系统可实际调用的供给边界
    - 检修、故障和受限情况会使名义装机与实际可用能力产生差异
  - 负荷变化决定需求峰谷与爬坡压力
    - 峰值水平、持续时长和快速爬坡共同影响平衡压力出现的时点与强度
  - 市场互济改变本地缺口可被外部资源缓释的程度
    - 跨区跨省交易和可调用互济能力会改变本地供需缺口的实际风险水平
  - 天气和新能源偏差增加短期供需的不确定性
    - 温度变化、风光出力偏差会同时影响需求和可用供给的短期波动

## 视觉结构

四个输入从不同方向汇入一个明确的“综合供需风险判断”结果区。每个输入保持独立入口和自己的 Evidence，不通过箭头相互串联。汇聚关系应突出“共同贡献”，结果区可进一步显示缺口规模、发生时段、风险概率等输出含义，但这些输出仍属于共同结果的解释。

## 演讲者备注

供需风险不能由单一指标替代。装机规模与实际可用能力之间可能存在差异，负荷峰值和爬坡速度会改变需求压力，外部互济又会改变本地缺口的实际影响。同时，天气和新能源偏差会把短期波动进一步放大。

因此，这几类因素需要在同一框架中共同进入研判。汇聚后的目标是回答缺口有多大、可能在什么时候出现、风险概率如何变化，从而形成可用于会商和预警的综合判断。

## 作者自检

1. 四个 Relation Units 都是独立输入贡献，且共同指向同一个结果。
2. 输入之间没有被虚构成先后步骤或因果链。
3. 每项 Evidence 只解释其输入为何影响风险判断。
4. 核心结论明确说明“为什么需要汇聚”，没有只列四类数据名称。
5. 视觉上所有输入都能看见共同汇入点，不能退化成四张平行卡片加一个孤立结论。
6. 上屏纯文本能恢复“多输入 → 共同结果”的关系。
