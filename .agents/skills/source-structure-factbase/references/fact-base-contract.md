# fact-base.json Contract

Entries are source assertions, not independently verified facts. Every entry is emitted with `claim_status=source_assertion`, `verification_status=unverified`, and `semantic_role=unclassified`. Paragraph/list/blockquote material becomes statement entries without rewriting. Each table body row remains a `table_record` trace parent and each non-empty cell emits one or more `table_cell_statement` children split on source punctuation. Child IDs use `<parent>-cNN-sNN`, record `parent_fact_id` and table coordinates, and do not consume the later parent-ID sequence. The child text mechanically joins row label, explicit column header and source cell text so downstream semantics can cite an atomic assertion with context. Every record preserves its originating block and Markdown line range. Headings, code fences and dividers do not become facts.

For an empty Markdown header, the first body row and its children retain `row_role=candidate_header` plus the parser's exact candidate coordinates. Their statements remain unchanged, their `table_cell.header` stays empty, and the row is not removed from the fact base. Only a separately confirmed structural role may later supply column context or metadata exclusion; wording, shortness or first-row position alone is insufficient.

When a later source-preserving stage has independent structural proof, it may project `metadata.table_header={status:"confirmed", row_index, line_start, cells}` onto the table source unit. Script coverage consumes that metadata only when the declared row coordinate agrees with the table locator and each projected record agrees with the same source line and the mechanically reconstructed cell statement.
