## p01

Create one polished Chinese enterprise architecture infographic on a 2048×1024 horizontal canvas. Use clean warm white, deep navy, electric cyan and restrained abstract power-grid line art. The whole composition is a single integrated architecture diagram. All labels must be physically embedded in architecture layers, vertical guard rails, or connected endpoint nodes. Do not create a left text column, a right illustration panel, a photo collage, body-copy cards, logos, subtitles, or a separate deployment block.

At the center, draw a unified vertical stack of five broad horizontal capability layers, read bottom to top. The layer labels and embedded capability text must be sharp, legible Chinese:
Bottom: “数据与人工智能基础” — “经授权数据与模型｜存储计算｜知识库｜向量检索｜模型服务｜算力资源管理”.
Above: “资源与产品管理” — “登记｜编目｜质量与版本管理｜数据产品封装”.
Above: “服务交付与场景编排” — “接口调用｜成果交付｜模型任务｜数据沙箱｜多方协同交付”.
Above: “运营与交易管理” — “客户｜产品规格｜订单｜合同｜授权｜计量｜账单｜结算”.
Top: “可信连接与主体接入” — “机构｜人员｜应用｜可信身份｜外部主体接入｜业务请求”. Show that this top layer has a clear downward connective spine through the four layers below; do not use a product-to-transaction lifecycle arrow.

Place two independent narrow vertical guard rails along the full height of the five-layer stack. Left rail: “安全与合规” with “分类分级｜权利核查｜访问控制｜输出管理｜审计追溯”, and make it visibly cover “主体接入｜产品开发｜服务调用｜成果交付｜计量结算｜退出管理”. Right rail: “标准与运维” with “目录｜接口｜质量｜服务等级｜计量标准｜版本｜监控｜容灾｜故障处置”.

Around the top trusted-connection layer, use four compact connected endpoint nodes, each explicitly joined by a line: “统一环境：公共能力集中部署”; “合作伙伴资源：可信连接器在源端提供服务”; “客户专属能力：专属实例或客户指定环境”; “受控计算环境：多方敏感数据联合分析”. These are connected environments around the platform, not an independent section.

Add only one compact in-diagram principle band at the top: “统一控制｜分布执行｜按需汇聚｜数据留域”. Use thin precise connectors, subtle icons inside their matching nodes, and a premium technical-blue vector infographic style. The architecture must be the entire visual story; avoid detached explanation text and avoid any generic process flow that reinterprets the architecture.
