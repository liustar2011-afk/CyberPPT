# 一、数据服务

数据服务以标准化、可复用的数据产品、知识资源和模型能力为主要运营对象，通过接口、数据集、知识库、模型任务、分析成果和持续监测等方式，为客户提供可订购、可调用、可计量的专业服务。数据服务主要包括基础查询、专业数据、行业知识、分析成果、模型算法、高质量数据集、持续监测和数据核验评价等类型。其中，基础查询和专业数据服务主要满足信息核验、研究分析、业务系统调用和模型训练需要；行业知识和分析成果服务主要提供政策标准、技术资料、专业报告、趋势研判、风险监测和辅助决策；模型算法服务主要提供预测、诊断、评价、优化、智能问答和报告生成；持续监测服务主要提供数据更新、指标监测、异常预警和周期分析。合作伙伴可以根据自身资源和能力，提供专业数据、行业知识、指标体系、分析成果、高质量数据集、模型算法或者持续监测能力。中电联数智公司与合作伙伴结合资源成熟度和客户需求，共同形成标准产品规格并开展协同运营。
