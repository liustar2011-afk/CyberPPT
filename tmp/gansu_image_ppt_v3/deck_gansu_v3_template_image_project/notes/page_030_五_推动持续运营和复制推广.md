# 五、推动持续运营和复制推广

试点完成后，中电联数智公司会同合作伙伴开展评估，根据试点运行和应用评价情况持续优化产品内容、服务方式、价格机制和运营规则。达到约定条件的产品和场景，纳入平台统一目录、客户服务、服务权益、计量结算和质量评价体系，转入正式运营。产品或者场景转入正式运营，原则上具备客户价值已经验证、产品质量达到要求、交付方式稳定、权利和安全边界明确、计量结算能够执行、合作各方具备持续服务能力等条件。对服务质量稳定、业务价值明确、客户认可度较高的产品和场景，中电联数智公司会同相关合作伙伴形成标准产品规格、场景服务包、接口规范、配置参数、实施清单和典型案例，通过行业交流、成果发布、示范应用和生态合作等方式有序推广。中电联根据需要组织行业成果发布、示范推广和生态合作。中电联数智公司会同相关合作伙伴定期开展产品组合分析，根据产品应用、服务质量和投入产出情况，共同优化资源投入、市场推广和产品运营安排，持续提升平台产品有效供给和经营可持续能力。
