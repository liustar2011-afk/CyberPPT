# 四、数据安全、权利与衍生成果

平台按照国家数据安全、网络安全、个人信息保护和电力行业有关规定，建立覆盖主体接入、资源登记、产品开发、授权使用、服务调用、成果交付、计量结算和退出管理的安全保障体系，坚持权利清晰、授权使用、用途限定、最小必要、安全可控和全过程留痕。合作伙伴原始数据原则上保留在自身控制域内。确需传输、汇聚或者交付的数据，明确数据范围、服务对象、使用目的、授权期限、输出方式和安全措施。平台严格按照约定的客户范围、产品范围、使用目的和授权期限使用合作伙伴资源；涉及模型训练、产品扩展或者其他用途的，另行取得合作伙伴明确授权。合作伙伴接入平台后，其核心模型、模型权重、算法、软件、专业知识和既有知识产权继续保持原有归属。合作形成的治理加工数据、指标标签、联合分析结果、模型参数、场景方案、软件组件和其他衍生成果，根据资源来源、各方投入、形成过程和具体协议明确归属、使用范围、收益安排和后续改进权益。
