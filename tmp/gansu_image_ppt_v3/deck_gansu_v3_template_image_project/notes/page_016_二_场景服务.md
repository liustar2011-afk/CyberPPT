# 二、场景服务

场景服务围绕客户具体业务问题，综合运用数据、知识、模型、算法、专家和技术实施能力，形成覆盖需求分析、方案设计、系统接入、试点运行、持续服务和成效评价的综合服务。一是标准场景服务。数据、模型、流程和交付成果相对固定，能够按照统一服务说明快速复制，适用于行业知识检索、企业信息核验、设备可靠性分析、电碳因子查询和周期性行业监测等成熟服务。二是配置型场景服务。核心能力和业务流程已经标准化，可以根据客户区域、组织、设备、指标和业务参数进行配置，适用于具有共性业务逻辑、需要结合客户实际条件灵活实施的场景。三是定制型场景服务。面向重大客户和复杂业务问题进行专项设计，根据需要开展数据治理、模型开发和系统集成。项目实施过程中同步沉淀可复用的数据产品、模型组件、接口、业务规则和实施清单，逐步提升标准化和配置化水平。
