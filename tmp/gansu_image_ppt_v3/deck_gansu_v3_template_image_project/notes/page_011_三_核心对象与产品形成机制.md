# 三、核心对象与产品形成机制

中电联数智公司依托平台对数据资源、数据产品、数据服务和场景服务四类核心对象实施分类管理，分别明确管理边界、准入条件和运营责任。一是数据资源。数据资源是进入平台登记管理的数据、知识、文档、模型、算法和其他可利用能力，重点说明资源内容、存放位置、权利主体、使用范围、质量状况和提供条件。完成资源登记后，可根据客户需求和合作条件进一步开展产品化开发。二是数据产品。数据产品是经过权利确认、治理加工、质量检验、标准封装和版本管理，可以作为独立对象进行管理的数据成果。每个数据产品明确唯一编码、提供主体、资源来源、数据口径、质量等级、版本更新、使用边界和交付方式。三是数据服务。数据服务是基于数据产品、知识资源或者模型能力形成的，可供客户订购、调用和计量的专业服务。数据服务重点明确目标客户、服务内容、交付成果、服务等级、服务期限、计量单位、价格规则和客户支持。
