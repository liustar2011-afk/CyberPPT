# 五、服务质量保障与风险协同处置

各方共同建立覆盖数据质量、服务可用性、响应时效、模型效果、客户满意度、业务成效、安全合规和商务履约的服务质量保障机制。中电联数智公司依托平台开展运行监测、客户服务和协同处置，合作伙伴根据职责分工保障资源更新、接口稳定、模型可用和专业服务质量，共同处理质量问题、技术故障和客户反馈。产品内容、数据来源、模型版本、授权范围、交付方式、价格规则和服务等级发生变化时，各方按照约定履行变更确认、版本更新和客户通知程序。重大变化可能影响客户使用或者安全边界的，重新开展合规评估和试运行。发生越权调用、异常导出、违规使用、数据泄露、模型输出异常、重大质量问题或者服务中断时，中电联数智公司会同责任方按照应急预案开展访问限制、服务暂停、影响评估、恢复处置、客户通知、审计调查和整改，平台执行相应访问控制、停用和审计留痕措施。涉及监管要求的，依法依规配合相关工作。
