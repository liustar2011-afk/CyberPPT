# 三、完善合作实施方案

对确定的合作事项，各方根据资源条件、专业优势和实施需要协商确定牵头单位，共同编制数据产品说明、数据服务方案或者场景服务方案，明确服务对象、产品内容、资源来源、权利依据、交付方式、安全边界、服务等级、计量单位、价格机制、责任分工、实施里程碑和验收要求。中电联数智公司负责平台衔接、运营组织和综合协调。合作实施方案统筹明确首期合作成果、目标客户、应用价值、验证方式、技术实施、商务安排和转入正式运营的条件，形成贯通产品建设、客户应用和持续运营的实施安排。涉及多方联合实施的，各方共同组建专项工作组，根据资源能力和专业优势协商确定牵头单位、参与单位及职责分工，明确产品、数据、技术、安全、商务和运营责任；中电联数智公司负责平台运营协调和跨主体衔接。中电联组织审定平台运营和合作服务规则；中电联数智公司负责数据产品开发与生命周期管理办法、合作伙伴接入与协同服务指引、数据服务技术接入与安全规范、服务计量计费与结算管理规则、场景服务建设运营与验收指引等配套制度的起草、实施和持续完善，为具体合作和平台运营提供制度依据。
