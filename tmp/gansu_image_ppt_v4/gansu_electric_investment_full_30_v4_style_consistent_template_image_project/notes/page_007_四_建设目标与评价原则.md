# 四、建设目标与评价原则

项目围绕数据“供得出、流得动、用得好、保安全”的总体要求，重点建设可信连接、统一目录、数据流通利用、产品运营、场景协同、人工智能服务、安全管控和计量结算等能力。按照国家数据基础设施建设第二批先行先试任务安排，项目计划于2026年12月完成初验、2027年6月完成终验；到总体建设任务完成时，实现600家以上数据流通利用主体接入，支持5个以上重点行业的跨区域、跨行业数据流通利用，发布不少于1200个数据产品，打造20个以上示范性强、带动性广的典型应用场景。项目建设期重点评价平台能力、主体接入、资源汇聚、产品发布和示范场景建设情况；持续运营期重点评价产品实际应用、客户服务质量、场景业务成效、经营运行和生态协同情况，推动建设成果持续转化为行业服务能力。一是突出产品应用成效。重点评价产品上架、实际调用、持续更新、质量管理和动态优化情况。
