# 二、总体定位

电力领域数据基础设施的核心定位，是打造电力数据要素流通共享的行业中枢和价值释放的核心引擎。作为行业中枢，平台上接国家数据基础设施全域功能节点，横向对接区域节点、其他行业节点及相关数据流通体系，下联电力企业、能源企业、行业机构、科研院所、高等院校和相关业务系统，促进不同主体、不同区域和不同系统之间的数据资源互联互通、供需衔接和业务协同。作为核心引擎，平台对数据、知识、模型、算法和场景能力进行统一组织，通过资源登记、治理加工、产品封装、合规准入、服务上架、可信交付、统一计量和持续运营，推动数据资源向数据产品、数据服务和场景服务转化，促进专业能力规模化应用。平台立足中电联行业引领和服务职能，构建服务国家、赋能行业、支撑中电联内部发展的多层次服务体系，为政府宏观能源决策、新型能源体系和新型电力系统建设提供数据支撑，为电力企业生产经营、科技创新和数字化转型提供专业服务，为产业链上下游及跨行业主体协同创新创造基础条件。
