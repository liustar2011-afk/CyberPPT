# 一、总体业务主线

平台围绕“客户需求识别—资源和能力登记—权利、质量与合规审核—数据产品开发—数据服务或者场景服务封装—产品上架与客户订购—合同授权和使用控制—可信交付—服务计量—账单结算—服务评价与产品迭代”的主线组织建设和运营。需求侧由政府部门、电力企业、能源企业、科研院所、高等院校及跨行业主体提出业务需求、使用目的、交付成果和安全边界；供给侧由数据资源方、知识和模型提供方、技术服务方和场景实施方提供相应资源和专业能力。中电联数智公司负责组织供需对接和产品化运营，明确产品规则、服务责任和交付要求；平台按照合同授权和服务规则提供可信交付、计量记录和运行支撑。合作伙伴提供的数据、知识、模型和专业能力，经规范审核和产品化处理后，可以形成客户对象明确、交付方式清晰、价格规则合理、服务责任落实的数据产品、数据服务或者场景服务，并依托平台开展客户订购、受控使用、服务计量和收益结算。
