# 四、服务交付与服务等级

上述方向为平台重点培育领域。具体合作事项根据客户实际需求、资源和能力基础、权利合规条件、市场价值和持续运营可行性，按照成熟一项、推进一项的原则择优实施。一是远程接口和结果服务。适用于标准数据查询、专业指标、知识检索、模型推理、分析计算和报告服务，客户通过平台获得约定的数据结果、模型结果或者分析成果。二是专属实例服务。适用于对并发能力、响应时效、数据隔离和服务连续性有较高要求的客户，由平台配置专属数据空间、模型实例、连接器和服务保障资源。三是私有化部署服务。适用于集团级应用、敏感业务和长期运行场景，相关数据服务、知识库、模型或者场景应用部署在客户指定环境，并按照约定开展版本管理、运维保障和安全审计。四是数据留域受控计算服务。适用于设备运行、经营管理和联合建模等敏感场景，原始数据保留在合作伙伴或者客户控制域内，通过可信执行环境、数据沙箱、隐私保护计算或者联邦学习完成联合分析和结果输出。
