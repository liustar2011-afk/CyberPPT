# 四、组织开展试点运行

合作事项按照先验证、后运营，先试点、后推广的原则推进。中电联数智公司会同合作伙伴选择资源条件较好、客户需求明确、权利边界清晰、实施基础较为成熟的产品和场景开展试点。试点前，各方按照职责分工完成权利、合规、质量、技术、安全和商务条件确认，并根据交付方式完成接口、连接器、模型实例、数据空间或者应用系统接入。试点运行采用真实资源、真实客户、真实权限和典型业务条件，重点检验应用价值、产品质量、技术路径、交付稳定性、安全边界、服务权益、计量规则、成本结构、价格接受度和持续运营条件。试点同步了解客户使用意愿、采购方式、价格接受度和服务保障要求，共同确认各方后续资源投入、服务保障和持续运营安排，为正式报价、合同签署和后续复制推广提供依据。试点期间记录服务调用、可用性、响应时效、客户反馈、业务成效、服务成本和运营问题，形成试点评估报告。达到预定条件的，转入正式运营；需要进一步完善的，明确产品优化和再次验证安排；不具备持续运营条件的，各方按照合作协议研究暂停或者终止相关事项。
