# 三、商务定价与收益结算

商务定价坚持市场需求牵引、服务价值定价、成本合理覆盖、贡献可核验和收益合理分享，综合考虑资源质量、专业价值、授权范围、服务等级、交付方式、使用规模、稀缺程度、可替代性和市场接受度等因素确定。标准数据、知识、模型和持续监测服务，可以采用年度订阅、按量调用、产品套餐、用户或者对象数量、服务周期和成果交付等方式计价；需要技术适配、专属环境或者资源保障的，可以收取接入、专属实例、算力资源、数据加工、安全保障和运维服务等费用；场景服务按照建设实施、数据服务使用、模型与算力、年度运营和专业人员服务等费用构成计价；私有化部署、定制数据集、联合建模、系统集成和专项开发等非标准服务，按照项目范围、实施周期、资源投入和交付成果协商确定价格。可分配收入一般以客户实际确认收入为基础，扣除税费、退款、合同约定的云和算力等直接成本以及必要的第三方成本后，按照具体合作协议开展分配。标准化服务可以采用供给方结算价格与平台运营服务相结合的方式；多方联合产品可以按照约定比例、有效计量结果或者可核验工作量分配；场景服务可以按照建设里程碑、持续运营责任、实际工作量、交付成果和服务成效进行结算。
