# 二、合作伙伴全周期协同服务

中电联数智公司依托平台提供合作对接、技术支撑、产品运营和市场协同等服务，会同合作伙伴建立“合作意向沟通—资源能力对接—合作条件确认—产品与场景共建—联合运营—成效评估—优化调整”的全周期协同服务机制。合作条件确认阶段，各方围绕主体资质、资源权利、数据质量、技术条件、安全能力、服务保障、市场需求和持续运营条件开展充分沟通和核实。中电联数智公司同步说明平台能力、接入要求、服务流程、商务机制和权益保障安排；涉及重要数据、个人信息、模型训练和跨主体联合计算的，按照有关规定开展专项评估。合作运营期间，各方根据服务运行、客户反馈、产品应用、安全合规、商务履约和合作成效，共同开展阶段性评估。评估结果用于优化产品服务、完善协同分工、调整支持方式和研究后续合作安排。中电联数智公司根据合作事项类型、产品成熟度、服务需求和实际合作成效，为合作伙伴提供差异化的产品开发、技术接入、市场对接和运营推广支持。具体合作事项、资源投入和权益安排由各方通过协议明确。
