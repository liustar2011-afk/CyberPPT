# 五、服务运营与计量结算机制

平台以订单履行为主线，建立贯通客户账户、产品规格、服务订单、商务合同、数据授权、服务权益、授权执行、调用交付、计量记录、客户账单和合作伙伴结算的业务关系。产品规格明确客户购买的版本、范围、服务期限、服务等级和计价条件；商务合同约定各方权利义务和财务责任；数据授权明确数据和成果的使用目的、范围和期限；服务权益将订单转化为可执行的服务额度、用户数量、服务范围和有效期限；授权规则下发至连接器、服务网关、模型节点或者场景系统执行。平台根据服务请求和交付结果记录计量信息。数据接口服务可根据调用次数、返回记录、数据量、查询对象或者并发能力计量；数据集服务可根据数据版本、数据规模、授权期限、使用主体和使用目的计量；知识服务可根据用户数量、检索次数、知识范围或者专属空间计量；模型服务可根据任务次数、推理量、模型实例、算力时长或者并发能力计量；监测和报告服务可根据监测对象、指标数量、成果频次和服务周期计量。
