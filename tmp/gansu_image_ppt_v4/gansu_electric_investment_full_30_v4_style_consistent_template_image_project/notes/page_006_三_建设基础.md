# 三、建设基础

中电联长期承担行业联系、统计分析、标准协调、专业研究、会员服务和政策沟通等职责，拥有覆盖电力产业链主要环节的会员生态、专业机构和行业服务渠道，形成了政策标准、行业统计、可靠性、绿色低碳、科技成果、信用评价、人才教育和专业研究等方面的数据资源与业务基础。电力公共信息平台及相关业务平台为项目建设提供了既有技术和运营基础。中电联正在推进内部资源协同、行业数据资源池建设、重点场景论证、关键技术研究和行业生态合作，并与电力骨干企业、科研机构、专业服务机构开展数据资源价值评估、可信数据空间互联和重点场景合作研究。项目按照先研后建、稳步推进的原则组织实施，已完成可行性研究和建设方案论证，进入建设实施阶段。平台建设、数据资源汇聚、数据产品开发、重点场景培育、合作伙伴协同和运营制度建设同步推进。
