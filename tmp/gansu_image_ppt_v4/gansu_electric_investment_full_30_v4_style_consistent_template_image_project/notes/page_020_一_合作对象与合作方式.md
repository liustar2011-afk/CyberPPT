# 一、合作对象与合作方式

平台合作坚持平等自愿、优势互补、权责对等、成果共享。在平台建设运营中，中电联负责建设统筹、重大事项协调、规则审定和行业推广；中电联数智公司代表中电联承担平台运营、产品组织、客户服务和协同交付责任，是合作伙伴和需求单位的日常对接主体；平台作为技术和业务运行载体，提供身份认证、授权控制、服务交付、计量记录和审计留痕等支撑；合作伙伴根据合作分工承担资源提供、专业实施和持续服务责任；需求单位（客户）负责提出业务需求、订购使用、成果确认和应用反馈。各方按照合作协议履行相应责任；涉及多方联合实施的产品和场景，共同建立专项工作机制。各类电力企业、能源企业、科研院所、高等院校、数字科技企业、数据服务机构、技术服务机构、专业咨询机构和生态组织，可以结合自身资源条件和业务优势参与合作。合作内容主要包括资源与能力合作、产品与场景合作、市场与生态合作。
